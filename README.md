# アニメカタログ

新番組・放送中・劇場アニメを、**ポスターで見渡す**ための個人用カタログです。

- データ元：[AniList](https://anilist.co) の公開GraphQL API のみ
- 366作品／タグ・ジャンル・時期・珍しさで **30の棚**に分けています
- **🎞 予告編タイム**：棚ごとに予告編を次々と再生します
- **🆕 前衛的**：好みを一切見ず、「世間にその言葉がほとんど無い」ものだけを拾います

## 記録について

♥（みたい）や★は、**開いた端末のブラウザの中だけ**に保存されます。
サーバーには送られません。誰にも共有されません。
